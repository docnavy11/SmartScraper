Rules
●Density beats comfort. 28px table rows, 12px mono cells, tabular numerals.
●Status is a glyph plus a word, never colour alone.
●Purple marks anything an LLM authored: versions, rows, spend.
●Held delivery and pending approval both read amber, never red. Nothing is broken yet.
●Red is reserved for a run that failed or a site that blocked us.
●Real button, anchor, input and label elements even in a mockup, so Tab reaches them.
●Text meets 4.5:1. text-3 is the floor and never goes below 10.5px.
●No shadows, no gradients, no emoji. Icons are 1.75px stroke SVG.
